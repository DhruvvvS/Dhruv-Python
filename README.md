# Dhruv-Python

A growing collection of Python projects, scripts, and solved practice problems.

## What's Inside
- Core Python exercises (loops, functions, OOP basics)
- Small automation/utility scripts
- Practice problems with solutions
- Mini-projects applying Python fundamentals

## How to Run
Most scripts can be run directly with Python 3:

```bash
python filename.py
```

If a specific project needs extra libraries, install them with:

```bash
pip install -r requirements.txt
```
